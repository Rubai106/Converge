## Profiles and services
- Start with BOTH: `docker compose --profile collab --profile gateway --env-file .env -f standalone-docker-compose.yml up -d`
- `collab` = `mattermost` (port 8065); `gateway` = `switch-gateway` (port 3000).
- Always started: `switch-postgres` (5432), `switch-core` (8000), `switch-setup`, `switch-auth`, `init-db`.
- Health: `curl http://localhost:8000/healthz` (core), `curl http://localhost:3000/healthz` (gateway).
- All host ports bind `${SWITCH_BIND_ADDR:-127.0.0.1}` by default (loopback only).

## Required .env (secrets generated, never committed)
- `SWITCH_VERSION=0.31.0`, `CANONICAL_HOSTNAME` (loopback-only here: use `localhost`),
  `OWNER_EMAIL`, `SECRET_KEYS=label:$(openssl rand -hex 32)`.
- Generated by `deploy/local/generate-env-secrets.sh` (each `openssl rand -hex 24`,
  SECRET_KEYS `-hex 32`): `DB_PASSWORD`, `DB_OWNER_PASSWORD`,
  `AGENT_REGISTRATION_TOKEN`, `GATEWAY_ADMIN_PASSWORD`, `MATTERMOST_ADMIN_PASSWORD`,
  `MATTERMOST_USER_PASSWORD`.
- Slack tokens only if connecting Slack (not needed — Mattermost is the chat).
- Two Postgres roles: `DB_USER` (runtime, NOT table owner — core refuses to start
  if it is the owner), `DB_OWNER_USER` (schema owner, migrations only).
- `.env` lives in `~/workspace/switch-server/.env` — NEVER in the converge repo.

## Agent management (after first start)
```
docker compose --env-file .env -f standalone-docker-compose.yml exec switch-core switch workspace add owner-workspace
docker compose --env-file .env -f standalone-docker-compose.yml exec switch-core switch workspace create-admin-token owner-workspace workspaces.can_manage_agents
docker compose --env-file .env -f standalone-docker-compose.yml exec switch-core switch gateway set-public-url http://localhost:3000
```

## Caveats
- The standalone compose file carries a notice that standalone mode is obsolete in
  favour of `just up` (Mattermost workspace) / `just gateways` — the docs page
  still publishes it as the Compose path, so it is the path we try first.
- VM constraints (2026-11-05): 7.4 GB disk free, ~480 MB memory available.
  Postgres + Mattermost + switch-core + gateway may not fit — to be determined
